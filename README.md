# Assignment 3 – Selenium WebDriver (Python)

## Project name
selenium_python_gauharbek_assignment3

## Description
This project is created as part of Assignment 3 for Software Quality Assurance and Testing.
All tests are automated using Selenium WebDriver with Python.

The project includes:
- Search functionality test
- Login and Logout test
- Flight booking test with title checkpoint

Different web applications are used to ensure project uniqueness.

## Technologies
- Python 3
- Selenium WebDriver
- webdriver-manager
- Google Chrome

## Web Applications Used
1. Search: https://www.wikipedia.org/
2. Login/Logout: https://the-internet.herokuapp.com/login
3. Flight booking: https://blazedemo.com/

## How to run tests
1. Install Python 3
2. Install dependencies:
   pip install -r requirements.txt
3. Run tests individually:
   python tests/test_search.py
   python tests/test_login_logout.py
   python tests/test_flight_booking.py

## Test Design Techniques
- Smoke and regression logic
- Equivalence class testing
- Assertions (checkpoints)
- Title checkpoint for flight booking

## Notes
CSS selectors and XPath locators are used as required by the assignment.
